# Отчёт: использование нереляционных баз данных в проекте

## 1. Цель работы и задачи
**Цель работы:** показать на практике, как нереляционная база данных используется вместе с реляционной в одном приложении для повышения производительности (паттерн Cache-Aside).

**Задачи:**
* Реализовать реляционное хранилище для основных данных (SQLite).
* Реализовать нереляционное хранилище (имитация Redis на основе Key-Value словарей в памяти).
* Настроить кэширование данных с временем жизни (TTL) и продемонстрировать работу кэш-попаданий и кэш-промахов.

## 2. Архитектура
В проекте используется подход Polyglot Persistence. Основное хранилище — реляционное, вспомогательное — нереляционное (кэш).

* **Основное хранилище (SQLite):** используется для надежного хранения товаров (таблица `products`). В реальном проекте здесь была бы PostgreSQL.
* **Кэш (MockRedis):** используется для хранения часто запрашиваемых данных в оперативной памяти с ограниченным временем жизни (TTL).

## 3. Сценарии взаимодействия (Cache-Aside)
1. **Заполнение БД:** При запуске скрипт автоматически создает файл `shop.db`, таблицу `products` и наполняет её тестовыми данными.
2. **Чтение данных (Cache Miss):** Программа сначала обращается к кэшу (Redis). Если данных там нет, она читает их из SQLite и помещает в Redis на 5 секунд.
3. **Чтение данных (Cache Hit):** При повторном запросе в течение 5 секунд программа берет данные прямо из памяти, не обращаясь к реляционной БД.
4. **Истечение TTL:** Через 5 секунд кэш устаревает. При следующем запросе программа снова идет в SQLite и обновляет кэш.

## 4. Запуск проекта
Для запуска проекта необходим установленный Python. Дополнительные библиотеки не требуются.

Запустите скрипт командой:
python app.py

При запуске в терминале будут выведены логи работы программы, демонстрирующие попадания в кэш и запросы к реляционной базе данных.

## 5. Вывод
Использование нереляционной БД (Redis) в качестве кэша позволяет значительно снизить нагрузку на основную реляционную базу данных и увеличить скорость ответа системы. Паттерн Cache-Aside отлично подходит для чтения редко изменяемых данных (например, каталога товаров).

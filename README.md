# Отчёт: использование нереляционных баз данных в проекте ShopLite (Python)

## 1. Цель работы и задачи
**Цель работы:** показать на практике, как нереляционная база данных используется вместе с реляционной в одном приложении для повышения производительности (паттерн Cache-Aside).

**Задачи:**
* Реализовать реляционное хранилище для основных данных (SQLite).
* Реализовать нереляционное хранилище (имитация Redis на основе Key-Value словарей в памяти).
* Настроить кэширование данных с временем жизни (TTL) и продемонстрировать работу кэш-попаданий и кэш-промахов.

## 2. Архитектура
В проекте используется подход Polyglot Persistence:

```text
       Пользователь / Скрипт
               |
       Python приложение (app.py)
           /           \
          /             \
   Реляционная БД    Нереляционная БД
      SQLite             MockRedis
    (файл shop.db)      (кэш в памяти)
